# 手工织锦纹样排版台 · 色线预算版

直接打开 `index.html` 使用（无需构建）。在色号库存约束下绘制经纬网格纹样，
整笔替换色号并保持画布、撤销重做、用色统计、重复预览、导出 JSON 一次同步。

## 功能闭环

- **色线按色号维护库存**：8 个固定色号（W01…K07/O08），左侧可直接修改各色号库存（格）。
- **色号整笔替换**：右侧选择源色号与目标色号，实时预估替换后用量/缺口；
  库存不足时**整次拒绝**——画布不改动、不写历史、预算版本不 bump、导出不变，不留半成品。
- **填色同样受库存约束**：一笔拖动记一条历史；中途超出库存则整笔回滚。
- **调整网格保留重叠区域**：缩小时重叠格原样保留；被裁掉的图案保存为「最近版本」，
  网格下方一键恢复；**恢复后旧预算立即作废并按新画布重算**（预算单版本号 +1）。
- **渲染预算单**：按色号列出用量 / 库存 / 余量 / 超支，带版本号；
  画布、统计、预览、导出共用同一次提交的核算结果。
- **持久化**：每次成功提交自动写入 `localStorage`（key：`zfl31Tapestry.v2`），
  含画布、库存、历史栈、预算版本、最近裁剪版本，刷新后全部一致；
  旧版 `zfl31Pattern`（颜色下标注法）首次打开时自动迁移。

## 模块拆分（互不混用职责）

| 文件 | 职责 |
| --- | --- |
| `js/history.js` | 历史记录模块：撤销/重做栈，每条对应一次原子操作，可序列化 hydrate |
| `js/budget.js` | 渲染预算模块：按色号对账需求与库存，签名变化即作废旧结果并重算，版本化 |
| `js/storage.js` | 持久化模块：整份状态一次存取；旧版数据迁移；localStorage 不可用时降级内存 |
| `js/state.js` | 状态规则模块：库存校验、原子提交（唯一改动入口）、替换/填色/调网格/恢复规则 |
| `js/app.js` | DOM 层：把一次提交结果同步刷新到画布、撤销重做、预算、统计、预览、导出 |

## 测试

```bash
node tools/smoke.js
```

40 项断言覆盖：库存不足的整笔拒绝与零半成品、替换后五处同源更新、
撤销重做、网格重叠保留、裁剪恢复强制预算失效重算、刷新重建后状态一致。
