# 手工织锦纹样排版台

直接打开 `index.html` 使用（无需构建、无需服务器）。

## 功能

- **网格绘制**：点击 / 拖动填色，单点、十字、小菱形三种纹样块。
- **色线按色号维护库存**：8 个色号各有库存（单位：格），调色板实时显示剩余；落笔与替换都受库存约束。
- **色线整幅替换（预算闭环）**：一次事务同时更新画布、撤销 / 重做、用色统计、重复预览与导出；目标色号库存不足时整次拒绝，画布、历史、统计全部保持原样，不留半成品。
- **调整网格保留重叠区域**：缩放以左上角对齐保留重叠部分；缩小被裁掉的图案可从"最近版本"一键恢复，恢复后旧预算立即失效并重算。
- **撤销 / 重做**：全部画布操作（落笔、替换、缩放、新建、恢复）各占一步历史，支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。
- **用色统计、重复单元预览、断线风险提示、本地保存与导出 JSON**（导出含各色号库存 / 用量 / 余量）。
- **刷新后一致**：画布状态、色号库存、撤销重做历史、裁剪版本快照全部持久化到 localStorage，刷新后原样恢复；旧版存档自动迁移。

## 模块划分

| 文件 | 职责 |
| --- | --- |
| `js/state.js` | **状态规则**：文档状态定义，落笔 / 替换 / 缩放的校验（plan）与执行（apply），序列化与旧版迁移。plan 不通过则 apply 不会被调用，保证整次拒绝。 |
| `js/history.js` | **历史记录**：撤销 / 重做栈 + 裁剪前的"最近版本"快照，可整体序列化。 |
| `js/budget.js` | **渲染预算**：由画布推导各色号用量 / 余量；状态一变即 `invalidate`（旧预算立即失效），读取时重算；负责预算面板渲染。 |
| `js/main.js` | 主控：装配三个模块，统一事务入口（plan → 记录历史 → 应用 → 预算失效 → 持久化 → 整体重渲染），负责 UI 与事件。 |

模块间约定：`budget.js` 不依赖任何人；`state.js` 只引用 `budget.js` 的计数函数；`history.js` 完全独立；`main.js` 单向装配。所有模块同时兼容浏览器（`window.Brocade*`）与 Node（`module.exports`）。

## 测试

```bash
node --test tests/
```

- `tests/modules.test.js`：三个模块的单元测试（替换原子性、重叠保留、版本恢复、预算失效重算、序列化往返等）。
- `tests/app.smoke.test.js`：最小 DOM 垫片下加载真实页面脚本，走通落笔 → 调库存 → 替换（拒绝 / 成功）→ 撤销重做 → 缩放 → 恢复 → 保存的全流程。
